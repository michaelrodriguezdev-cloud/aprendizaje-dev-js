# Aprendizaje Dev JS 🚀

Este es un repositorio de práctica diaria orientado a aprender desarrollo web fullstack, 
con el objetivo de estar listo para mi primer empleo como developer.

## Sobre este repositorio

Este espacio documenta mi progreso día a día: ejercicios, retos y 
proyectos mientras construyo las bases de JavaScript antes de avanzar 
a React, Node.js y bases de datos.

## ¿Por qué empece esto?

Decidi empezar a estudiar por mi cuenta ya que la institucion donde estoy (SENA)
aun no se ha orientado a aprender lenguajes de programación a fondo, por lo cual quiero
sentir que avanzo sin depender de la maya curricular del programa de formación

## Semana 1 — Fundamentos de JavaScript

- **Día 1**: Variables, funciones, condicionales, loops (for/while)
- **Día 2**: Arrays y sus métodos (`.forEach`, `.map`, `.filter`)
- **Día 3**: Objetos, dot notation, arrays de objetos
- **Día 4**: Repaso y reconstrucción de memoria (spaced repetition)
- **Día 5**: Arrow functions
- **Día 6**: Git y GitHub — primer repositorio

## Tecnologías

- JavaScript (Node.js)
